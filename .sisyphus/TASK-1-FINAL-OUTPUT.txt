================================================================================
TROUBLESHOOTING GUIDE
================================================================================

ISSUE: "Column already exists"
CAUSE: Migration already applied or run twice
SOLUTION: Check Supabase Table Editor; if column exists, migration is done
          Skip to Step 3 (verification script)

ISSUE: "Constraint violation" on products.category
CAUSE: Some products have invalid category values
SOLUTION: Manually update products with invalid categories first
          Then re-run the migration

ISSUE: "Permission denied"
CAUSE: Not logged in as project owner in Supabase
SOLUTION: Ensure you're using your Supabase account credentials
          (not the anon key from .env)

ISSUE: verify-schema fails
CAUSE: Missing environment variables or incorrect credentials
SOLUTION: Check .env has correct VITE_SUPABASE_URL and VITE_SUPABASE_ANON_KEY
          Run: npm install (to ensure @supabase/supabase-js is installed)
          Run: npm run verify-schema again
